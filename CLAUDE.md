# basecamp-sandbox

Project for testing BaseCamp releases.

Read `~/.claude/basecamp/practices.md` and follow it, all of it.

## Commands

| Command | What it does |
|---|---|
| `just fmt` | Formats the code |
| `just lint` | Runs the linter |
| `just test` | Runs the tests |
| `just check` | All of the above, checking without changing anything |
